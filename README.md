### 🚀 Projetos em Destaque

*   🏪 **[Sistema Lan House - API REST](https://github.com/MuriloDev07/Projeto-Sistema-LanHouse)**
    API desenvolvida do zero para gerenciar o estoque de um negócio físico real (v2.8.0). Refatorada para o padrão **Application Factory** com esteira automatizada de **CI/CD via GitHub Actions**, o projeto garante rigorosa separação de preocupações (SoC) entre produção e testes. Construída com Flask, SQLAlchemy e **PostgreSQL**, inclui autenticação segura (JWT) com injeção de *claims* de autorização, controle de acesso baseado em papéis (**RBAC**) via decorador customizado `@admin_required` e validação tipada (Marshmallow). A confiabilidade e a qualidade são asseguradas por uma suíte isolada de testes automatizados no Pytest (100% de cobertura), com todo o ecossistema orquestrado e protegido por *healthchecks* no **Docker Compose**.

*   🖥️ **[Sistema de Cadastro de Alunos - CLI em C](https://github.com/MuriloDev07/Sistema-de-Cadastro-de-Alunos)**
    Aplicação de linha de comandos (CLI) desenvolvida integralmente em C para gestão acadêmica. O projeto foca em arquitetura modularizada (separação de lógica de negócios, interfaces e manipulação de arquivos `.txt` para persistência de dados) e utiliza **Make** para automação da compilação em ambiente Linux. O sistema agora é conteinerizado com **Docker**, garantindo um ambiente perfeitamente isolado para compilação e execução.

*   🩺 **[Verificador de Receitas Médicas com OCR](https://github.com/bcord1/projeto_algoritmos)**
    Sistema acadêmico em equipe para automatizar a leitura de receitas. Atuei diretamente no back-end arquitetando a lógica de validação de credenciais médicas (CRM/UF). Cruzei dados extraídos por Visão Computacional (OpenCV e Tesseract) com um banco relacional, implementando tratativas robustas para lidar com artefatos e falhas de leitura do OCR.

### 🚀 Featured Projects

*   🏪 **[Lan House System - REST API](https://github.com/MuriloDev07/Projeto-Sistema-LanHouse)**
    An API built from scratch to manage the inventory of a real physical business (v2.8.0). Refactored to the **Application Factory** pattern featuring an automated **CI/CD pipeline via GitHub Actions**, ensuring strict Separation of Concerns (SoC) between production and testing environments. Built with Flask, SQLAlchemy, and **PostgreSQL**, the system features secure authentication (JWT) with authorization claims, Role-Based Access Control (**RBAC**) via a custom `@admin_required` decorator, and typed data validation (Marshmallow). Reliability and quality are ensured by an isolated automated test suite using Pytest (100% coverage), with the entire ecosystem orchestrated and protected by healthchecks in **Docker Compose**.

*   🖥️ **[Student Registration System - CLI](https://github.com/MuriloDev07/Sistema-de-Cadastro-de-Alunos)**
    A Command-Line Interface (CLI) application built entirely in C for academic management. The project focuses on a modularized architecture (separating business logic, interfaces, and `.txt` file manipulation for data persistence) and utilizes **Make** for build automation in a Linux environment. The system is now containerized using **Docker**, ensuring a perfectly isolated environment for compilation and execution.

*   🩺 **[OCR Medical Prescription Verifier](https://github.com/bcord1/projeto_algoritmos)**
    A team-based academic project to automate the reading of medical prescriptions. I worked directly on the back-end, architecting the validation logic for medical credentials. I cross-referenced data extracted via Computer Vision (OpenCV and Tesseract) with a relational database, implementing robust exception handling for OCR artifacts and read failures.
